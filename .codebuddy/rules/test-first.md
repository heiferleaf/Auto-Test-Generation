# 测试先行规则

适用：本项目所有实现任务（参见 CODEBUDDY.md §5）。

## 规则

1. **在开展任何实现之前，都必须先有对应的测试代码或测试方案。**
2. 接收实现任务 → 先写/更新 `docs/实施计划.md` 中该阶段测试方案，或直接在 `test/` 落地测试骨架。
3. 实现代码以满足测试为第一目标，反复迭代直至测试通过。
4. **未通过测试不得视为完成**，不得合并。
5. 提交时 `npm test` 须全绿；CI/本地全绿才允许合并。
6. 测试类型约定：单测 `vitest`；集成/端到端用 Playwright Test 或自研执行器驱动示例 Electron App。
7. 示例 Electron App（开启 `--remote-debugging-port=9222`）作为端到端冒烟目标。
